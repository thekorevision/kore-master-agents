# Roadmap: kore-master-agents

From proven daily practice to a designed system. Each phase ends verifiable.

## Phase 1: Task model and logs
- Task records with states and verification blocks; run logs for every delegated job; resume points recorded on every stop.
- Exit test: any interrupted job can be resumed by a fresh agent from its task record alone, with no duplicated side effects.

## Phase 2: Guards as code
- Duplicate guard, verification harness, and approval router implemented as shared services every agent calls, not as habits in prompts.
- Exit test: a staged duplicate send and a staged unverified completion are both caught by the machinery in a drill.

## Phase 3: Memory discipline
- Curated memory with sources and supersession; people pages; mandatory memory check wired into task startup for history-dependent work.
- Exit test: an agent given a question about a past decision answers from the record, and cites it.

## Phase 4: Digest engine
- Daily decision queue generation: approvals, hands-only steps, deadlines, verified outcomes, ordered for a founder who reads on a phone.
- Exit test: a week of digests where every item the founder acted on was real, current, and correctly stated.

## Phase 5: Specialist fleet
- Named specialists (research, outreach, media, commerce, records) with bounded briefs and per-specialist guard profiles.
- Exit test: a multi-day campaign runs across specialists with zero duplicates and zero unverified claims in its reports.

## Phase 6: End state
- The workforce runs as infrastructure: the founder states outcomes, the system decomposes, executes, verifies, and returns decisions. New capabilities are added as new guards first and new powers second, so growth never outruns trustworthiness.
